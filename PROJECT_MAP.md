# Карта проекта

## Назначение

Локальная основа для триажа жалоб и репортов Grand Mobile. Выводит структурированный JSON и безопасный черновик.

## Реализованные модули

- `app/priority.py` — черновая политика приоритетов и обязательного участия человека; инструкция — `docs/annotation-guide.md`, схема внешней taxonomy — `configs/taxonomy.schema.json`.

- `scripts/inspect_data.py` — потоковая инвентаризация обращений и агрегатная проверка правил/taxonomy; результаты описаны в `docs/data-contract.md`.

- `app/schemas.py` — Pydantic-схема входа.
- `app/submission.py` — экспорт строковых цитат по примеру PDF; полный внутренний формат доступен для аудита. Контракт описан в `docs/api-contract.md`.
- `app/rules.py` — загрузка правил и однозначный поиск по разделу и пункту.
- `app/core.py` — нормализация, эвристическая категория/приоритет, решение об эскалации и черновик.
- `app/api.py` — FastAPI `POST /triage`, `GET /health`.
- `app/batch.py` — обработка JSONL/JSONL.GZ без изменения порядка строк.
- `tests/test_core.py` — ключевые сценарии безопасности и API.

## Запланировано

- Ручная разметка и обученный классификатор.
- История обращений и дедупликация; бонусный сценарий — 5 тикетов по одной проблеме от игрока за час.
- Расширенный поиск по правилам и оценка релевантности цитат.
- Оценка черновиков людьми, языковые срезы, стоимость, p95.
- Интерфейс администратора.

## Команды

- Тесты: `.\.venv\Scripts\python.exe -m pytest -q`
- API: `.\.venv\Scripts\python.exe -m uvicorn app.api:app --host 127.0.0.1 --port 8000`
- Batch: `.\.venv\Scripts\python.exe -m app.batch --input <jsonl> --output <jsonl> --rules <rules.json>`
