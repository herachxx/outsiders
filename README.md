# Grand Mobile Support — Outsiders

Локальная платформа обращений: форма игрока, очередь тикетов, вложения, операторская панель, проверка ответов и журнал изменений.

## Запуск на Windows 11

1. Скачайте ZIP из GitHub и **извлеките все файлы** в отдельную папку (не запускайте прямо внутри ZIP).
2. Дважды нажмите **`START_WINDOWS.bat`**. Это единственный файл запуска на Windows.
3. При первом запуске программа сама подготовит Python-окружение и откроет страницу настройки оператора в браузере. Придумайте пароль **один раз** (от 12 символов). После этого сразу откроется админка.
4. При следующих запусках будет открываться главная страница. Всё работает на вашем компьютере:
   - **Игрок:** http://127.0.0.1:8000/
   - **Оператор:** http://127.0.0.1:8000/admin

**Нужен Python 3.12+** (желательно 3.12 или 3.13). Если Python не установлен, установите его с https://www.python.org/downloads/windows/ и включите `Add Python to PATH`. **Интернет нужен только при первой установке Python-библиотек.** Отдельно устанавливать Ollama, создавать конфиги, вручную генерировать секреты или вводить команды в терминал **не нужно**.

Если окно сервера работает, не закрывайте его, пока пользуетесь платформой. Для остановки закройте окно или нажмите `Ctrl+C`. Повторный запуск — тот же `START_WINDOWS.bat`.

## Как пользоваться

- **Игрок** выбирает тему, вводит описание, прикладывает скриншот по необходимости и отправляет обращение. На экране появятся номер и предварительный ответ. При необходимости обращение направляется оператору.
- **Оператор** открывает `/admin`, вводит пароль и выбирает обращение в списке. Вкладки позволяют изучить сообщение, подготовить ответ, проверить материалы и историю, изменить статус.
- Чтобы сохранить обращения и пароль между версиями, **не удаляйте `data/`**. При замене проекта на новую версию перенесите папку `data/` из предыдущей установки в новую папку перед запуском.

## Локальная ИИ-модель и данные конкурса

**GitHub-версия намеренно не содержит конкурсные данные, закрытую базу правил и веса обученных моделей.** Она запускается как полноценная локальная система обработки тикетов с безопасным резервным ответом. Без указанных файлов нельзя честно обещать работу обученной модели.

Для закрытой командной демонстрации можно добавить **только разрешённые** веса CatBoost в `private/models/` (`category_model.cbm` и `classifier_meta.joblib`) и проверенный `rules.json` в `data/rules.json`; после перезапуска сервер обнаружит их автоматически. Не загружайте эти файлы в публичный GitHub без разрешения. Модель не переобучается при запуске.

Генерация текста через локальную Qwen/Ollama — **необязательная** функция. Если модель уже есть на компьютере и Ollama работает локально на `127.0.0.1:11434`, backend сможет использовать её для подготовки черновиков. Скачивание Qwen не запускается автоматически, облачных API в приложении нет. Чувствительные вопросы (жалобы, платежи, блокировки и безопасность аккаунтов) должны проверяться человеком. Без правил API `/triage` по конкурсному контракту возвращает 503, но форма игрока и админка работают.

Сама платформа не связана с официальным игровым API; изменение статуса здесь **не закрывает тикет внутри Grand Mobile**.

## Для разработчиков и проверяющих

```bash
python -m pip install -e ".[dev]"
python -m pytest -q
```

Код сервера — `app/`, интерфейс — `app/ui/`, установщик — `scripts/windows_bootstrap.py`, автоматические тесты — `tests/`, техническая документация — `docs/`.

Приложение запускается только на `127.0.0.1`. Не публикуйте его в интернет как production-сервис без дополнительного security review. Все секреты, пользовательские данные, веса и приватные правила исключены из Git через `.gitignore`.
