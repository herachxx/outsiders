# Grand Mobile Support Copilot

Рабочая основа сервиса сортировки обращений для кейса Decentrathon 6.0. Текущая версия — **безопасный эвристический baseline**, а не готовое решение конкурса: категории и приоритеты в выданных данных не размечены, модель пока не обучена, тексты ответов шаблонные. Сервис не отправляет ответы и не назначает наказания.

## Быстрый старт (PowerShell)

```powershell
python -m venv .venv
.\.venv\Scripts\python.exe -m pip install -e '.[dev]'
$env:GRAND_RULES_PATH = 'C:\path\outside\repo\rules.json'
.\.venv\Scripts\python.exe -m uvicorn app.api:app --host 127.0.0.1 --port 8000
```

`POST http://127.0.0.1:8000/triage` принимает JSON обращения. `GET /health` показывает, загружены ли правила. Открытая схема API: `http://127.0.0.1:8000/docs`.

Пакетный режим:

```powershell
.\.venv\Scripts\python.exe -m app.batch --input C:\path\tickets_valid.jsonl --output C:\path\pred.jsonl --rules C:\path\rules.json
```

На каждую строку входа записывается одна строка результата. Некорректный JSON даёт `{"error":"invalid_input"}` на той же позиции. Файлы с данными и предсказаниями держите **за пределами репозитория**. Скрипт не меняет исходный набор.

## Реализовано

- общий pipeline для HTTP и JSONL;
- валидация входа и отказ от использования исторического ответа администратора как признака;
- первичная категоризация и приоритет по явным правилам;
- обязательная передача жалоб, платежей и вопросов об аккаунте человеку;
- составной ключ цитаты `(section_id, ref, rules_hash)` и отказ от неоднозначных пунктов;
- нейтральные черновики без обещаний наказания или возмещения;
- тесты базовых сценариев.

## Следующие задачи

1. Утвердить черновую taxonomy и протокол ручной разметки.
2. Разметить категории и приоритеты; создать независимый holdout по заявителям.
3. Обучить и оценить классификатор; откалибровать уверенность по языкам.
4. Реализовать поиск дублей по истории за пять часов и оценить ложные совпадения.
5. Улучшить подбор точного раздела правил, оценить релевантность цитат.
6. Проверить черновики администраторами и носителями казахского/узбекского.
7. Измерить p95 и стоимость на целевом оборудовании, затем добавить интерфейс администратора.

Полный [план](docs/implementation-plan.md) хранится в проекте. Сырые обращения, производные выборки, хеши игроков и содержимое правил нельзя публиковать в репозитории.
