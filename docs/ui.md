# E1: локальное рабочее место администратора

Запустите API через `scripts/run.ps1 -Action serve` с GRAND_RULES_PATH. Откройте `http://127.0.0.1:8000/`. Интерфейс включён в Python-пакет; Node, фронтенд-сборка и внешние шрифты не нужны.

Добавьте сообщение игрока, тип обращения и доступные сведения: сервер (в текущем контракте region), никнейм адресата жалобы, количество вложений, заявленные пункты правил. Вложения не загружаются и не анализируются. Результат появляется в очереди, отсортированной p0 → p3. Доступны исходный текст, отдельные утверждения, цитаты с разделом/хешем, причины маршрутизации и черновик. Очередь в браузере представляет только обращения, добавленные в этом интерфейсе, а не входящий поток реальной игры.

Правку можно сохранить кнопкой «Сохранить на устройстве»: вся текущая очередь записывается в localStorage текущего браузера и origin (схема/хост/порт). До нажатия изменения существуют только в памяти страницы. Данные приватные, но не зашифрованы; не использовать общий профиль браузера для реальных обращений. Очистка выполняется отдельной кнопкой с подтверждением. При недоступном/заполненном хранилище показывается ошибка. Сервер и Git не получают сохранённую очередь. Для простоты аутентификации и многопользовательского доступа нет: запускать только на localhost.

«Отметить для старшего» меняет локальную метку, не отправляет сообщение другому человеку. Для сохранения метки нажмите сохранение. Исходная категория и приоритет сервиса не меняются. История C3 не применяется из этой формы: она не передаёт reporter_hash/X-Ticket-ID.

«Проверить правку» вызывает POST /draft/check. Сервер заново определяет категорию и проверяет Draft через safety gate. Произвольная правка сохраняется, но не получает разрешение на копирование, поскольку gate пока допускает только шаблоны. «Восстановить шаблон» возвращает исходный текст. Копирование кнопкой доступно только после успешной проверки текущего текста; при любом изменении разрешение сбрасывается. Человек всё ещё может выделить текст обычными средствами браузера: это локальный инструмент, не механизм ограничения доступа. Отправки в игру и автоматических санкций нет.

Ошибки сервиса отображаются без содержимого внутренних исключений. При отсутствии правил интерфейс открывается, обработка возвращает 503. Неверная конфигурация модели может остановить сервер до открытия страницы — исправьте путь и перезапустите. Неоднозначные/несуществующие цитаты исключает backend; если сервер отклоняет правку, интерфейс не заменяет её автоматически, чтобы не терять работу.

Проверены выдача HTML/CSS/JS, отсутствие внешних ресурсов в HTML, успешная серверная проверка шаблона, отказ для опасной правки и режим без правил. Синтаксис JavaScript проверен Node. Автоматическая визуальная проверка и браузерная проверка сохранения/перезагрузки не выполнены: Chrome отсутствует, запуск Edge заблокирован политикой среды. Эти проверки нужно выполнить вручную перед реальным использованием.

Строка метаданных показывает полосу обработки из причин ответа (`handling_auto|review|escalate`): «можно ответить автоматически», «проверка администратором» или «решает администратор». Интерфейс сам ничего не отправляет.

## Предложение шаблонов по кластерам (бонус)

`python -m scripts.propose_templates --train tickets_train.jsonl.gz --output ../private/templates-report-v1.json --kind report` кластеризует обращения (TF-IDF + MiniBatchKMeans) и для каждого кластера предлагает самые частые **реальные ответы администраторов** с заменой ников, номеров и ссылок на плейсхолдеры `{nick}`, `{n}`. Ничего не выдумывается: шаблон появляется, только если администраторы уже так отвечали. В отчёте есть размер кластера, ключевые слова, доминирующая категория и поле `approved: null`: шаблон нужно утвердить вручную, автоматически он не включается. Отчёт приватный и хранится вне Git. На репортах train самый частый ответ — «Приветствую, слежу за вами» (до 45% кластера), поэтому полезнее запускать с `--kind complaint`.

Кнопка «Отправить» доступна только после успешной проверки правки (`/draft/check`) и ставит на обращение отметку об отправке: сообщение в игру не уходит, текст нужно отправить вручную. «Скачать правки для обучения» выгружает `grand-edits.jsonl` (отправленные, эскалированные и изменённые обращения: исходный и итоговый черновик, категория, приоритет, действие). Файл содержит тексты обращений и должен храниться вне Git; он служит обучающим сигналом из PDF.
