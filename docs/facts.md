# C2: факты и роли

`app/facts.py` извлекает наблюдения до первого ответа admin. Каждое наблюдение содержит kind, source, value и для текста start/end: индексы символов Python в исходной строке, end исключается. Пример source: messages[0].text. Это ссылки внутри исходного запроса, не постоянные глобальные идентификаторы.

claim — слова заявителя; reported_player_statement — слова другого игрока; metadata — исходные счётчики вложений. Отрицания сохраняются дословно. Пустые сообщения не образуют утверждений. Число вложений не означает, что содержимое просмотрено или нарушение доказано. Исходный images_count сохраняется как метаданные запроса; его корректность внешним источником не проверяется.

Тип verified намеренно не создаётся: интеграции с проверенным источником ещё нет. Ответ администратора из исторического датасета также не становится verified. Структура Fact используется внутри Python для дальнейшего генератора; публичный контракт остаётся прежним. extracted.claims теперь содержит отдельные исходные утверждения player вместо склеенного текста. Роли и ссылки доступны через extract_facts, без расширения JSON ответа.

Проверены роли, отрицание, точность offsets, вложения, пустой текст и отсечение истории. Семантическое извлечение отдельных событий, разрешение противоречий и проверка содержимого вложений не реализованы.
