# Проверка казахских текстов черновиков

Файл для носителя казахского языка. Слева русский оригинал (смысл), справа казахский текст из `app/templates/drafts.json`.
В колонке «Исправление» впишите правильный вариант или оставьте пустой, если текст верный. Править нужно смысл, грамматику, тон (вежливое «Сіз»), естественность. Код: `{refs}` в тексте заменяется списком пунктов.

Статус операции должен проверить администратор. | Төлемді тексеру үшін күнін, сомасын және операция нөмірін көрсетіңіз. Карта деректерін жасырып, түбіртекті тіркеңіз. ## Как собирается готовый ответ

Порядок: приветствие → вопрос по типу жалобы (`insult`, `cheat`, `dm`, `scam`, `rmt_ads`, `invalid`, `complaint`, `admin`) → `review` → материалы (`evidence_present` или `evidence_missing`) → `target_missing` → `server_missing` → `rules` → подпись `closing`. У репортов только короткое приветствие и один из ключей `payment`, `account`, `help`, `question`, `other`.

## Что проверить особенно

- Тон: обращение на «Сіз», без канцелярита.
- Игровые слова: «фрапс», «чат», «ник» — как говорят игроки в Казахстане.
- Нет ли обещаний («әкімші қарайды» — действие администратора, не итог).
- Для узбекского (uz) такая же проверка нужна носителю узбекского.
