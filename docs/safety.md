# D3: проверка готового черновика

`app/safety.py:check_draft` вызывается после генерации и перед сериализацией в общем TriageService. HTTP и batch используют один gate. Сначала проверяется строгая схема Draft, непустой текст и длина до 4000 символов. Неверная схема/неструктурированный JSON-ответ не выдаётся пользователю.

Каждая цитата проверяется по текущему RuleIndex: раздел, пункт, хеш версии, точный excerpt. Затем повторно проверяется тематическая релевантность и однозначность раздела. Неподтверждённая цитата приводит к замене всего текста, чтобы её номер не остался в прозе.

Текущий backend — детерминированные шаблоны. Gate сверяет весь черновик с ожидаемым шаблоном для запроса, категории, языка и проверенных цитат. Произвольные фразы, инструкции из обращения, лишние ссылки и ответы будущей LLM блокируются. Отдельный набор выражений блокирует известные обещания санкций/возмещения, утверждения о просмотре скриншотов и запросы секретов. Этот набор не является универсальным многоязычным семантическим детектором.

При отказе возвращается короткий независимый нейтральный fallback ru/kk/uz/en с пустыми cited, выставляется needs_human=true и добавляются safety_* причины. Confidence категории не изменяется: он не измеряет безопасность или качество текста. Никакие действия в игре, сообщения другим людям или выполнение инструкций из текста gate не запускает.

Граница доверия: шаблоны и код являются локальными доверенными ресурсами. Изменение общего файла шаблонов может изменить и генератор, и эталон сравнения; это требует code review и экспертной оценки текстов. Gate не доказывает фактическую истинность каждого предложения и не устраняет ограничения лексического retrieval. Для свободной генерации потребуется отдельный контракт backend, тестовый корпус и дополнительные проверки. LLM не включена.

Проверены корректный шаблон, текущая цитата, неверная схема, произвольный текст, обещание наказания/возмещения, запрос пароля, подмена версии правил и подмена генератора. На реальных adversarial обращениях и носителях языков качество ещё не измерено.
