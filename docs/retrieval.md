# D1: индекс и релевантность правил

`RuleIndex.search(text, category, ref=None, limit=5)` возвращает лексические кандидаты: объект Rule и число общих основ слов. Категории жалоб связаны с небольшим набором тематических выражений. Индекс не зависит от section_id=30 или фиксированных номеров пунктов.

Для цитирования сервис рассматривает только номера, указанные в rule_refs_raw. Поиск без ref доступен как инструмент получения кандидатов, но автоматически в ответ они не вставляются. Совпадение темы и явный запрет обязательны; определения и явные разрешения отсеиваются. Это предварительная русскоязычная эвристика, не семантическая модель и не доказанная релевантность.

При нескольких подходящих разделах цитата отсутствует: лексический балл не позволяет надёжно установить область применения. При одном кандидате сервис добавляет нейтральную ссылку для проверки администратором, не утверждая доказанность нарушения. Уникальность кандидата сама по себе не гарантирует применимость правила: ограничения сервера, мероприятия и исключения ещё требуют экспертной проверки. Полноценный вывод о допустимости санкции не делается.

Ключ цитаты: section_id + ref + rules_hash. validate_citation проверяет наличие пары в текущем индексе, совпадение хеша и точного excerpt (первые 180 символов). Изменение содержания правил делает старую цитату недействительной. Проверка существования отделена от релевантности; обе необходимы.

Проверены конфликтующие разделы, перенос номера в другой раздел, неизвестный пункт, повтор номера во входе, разрешение вместо запрета, изменившиеся правила и поддельный excerpt. Синтетические тесты не заменяют relevance@k на размеченных парах. Gold-пары и измерения recall/relevance ещё не подготовлены; D1 технически реализован с ограниченным лексическим покрытием.
