# D1: индекс и релевантность правил

`RuleIndex.search(text, category, ref=None, limit=5)` возвращает лексические кандидаты: объект Rule и число общих основ слов. Категории жалоб связаны с небольшим набором тематических выражений. Индекс не зависит от section_id=30 или фиксированных номеров пунктов.

Для цитирования сервис рассматривает только номера, указанные в rule_refs_raw. Поиск без ref доступен как инструмент получения кандидатов, но автоматически в ответ они не вставляются. Совпадение темы и явный запрет обязательны; определения и явные разрешения отсеиваются. Это предварительная русскоязычная эвристика, не семантическая модель и не доказанная релевантность.

При нескольких подходящих разделах цитата отсутствует: лексический балл не позволяет надёжно установить область применения. При одном кандидате сервис добавляет нейтральную ссылку для проверки администратором, не утверждая доказанность нарушения. Уникальность кандидата сама по себе не гарантирует применимость правила: ограничения сервера, мероприятия и исключения ещё требуют экспертной проверки. Полноценный вывод о допустимости санкции не делается.

Ключ цитаты: section_id + ref + rules_hash. validate_citation проверяет наличие пары в текущем индексе, совпадение хеша и точного excerpt (первые 180 символов). Изменение содержания правил делает старую цитату недействительной. Проверка существования отделена от релевантности; обе необходимы.

Проверены конфликтующие разделы, перенос номера в другой раздел, неизвестный пункт, повтор номера во входе, разрешение вместо запрета, изменившиеся правила и поддельный excerpt. Синтетические тесты не заменяют relevance@k на размеченных парах. Gold-пары и измерения recall/relevance ещё не подготовлены; D1 технически реализован с ограниченным лексическим покрытием.

Цитата по категории. Если игрок не назвал пригодный пункт, для уверенно определённых жалоб (confidence не ниже 0,7) берётся общий пункт taxonomy: оскорбление 2.1, читы 5.2, обман 4.1 (при «вымог/угроз» 4.2), реклама 2.3, а при сделке за реальные деньги 4.4. Пункт цитируется, только если он однозначно находится в одном разделе и его текст содержит запрет по теме категории; причина `citation_from_category`. Для DM, жалоб на администраторов и «другого» цитата не добавляется: подходящего общего пункта нет. На valid с моделью цитата есть у 524 из 1000 ответов (было 154 до цитат по категории), все существуют в правилах; релевантность по смыслу эксперт не проверял.

Жалобы без содержания (`complaint.invalid`): если в тексте нет описания (только ссылки, цифры, коды правил) цитируется п. 1.2.3 раздела «Правила жалоб» (нет точного описания сути), а при общих формулировках «разберитесь», «что это было» п. 1.3.4. Пункт находится по составному ключу и тексту в единственном разделе 31, для остальных обращений не добавляется.

Жалобы на администраторов и апелляции (`complaint.admin`, confidence не ниже 0,7) цитируют п. 1.3.1 «Правил жалоб»: в жалобе нужны скриншот наказания, описание, доказательства и ник администратора. Черновик просит именно это.

DM в зелёной зоне (текст содержит «зз», «зелёная», GZ или больницу) цитирует п. 1.1 раздела «Правила нахождения в Зелёной Зоне»: убийства и урон там запрещены независимо от причины. Для DM вне зоны цитаты нет.

Пункты по taxonomy.json (организаторы указали их для категорий): жалобы на администраторов и апелляции цитируют 1.3.1 «Правил жалоб» и 3.4 («жалобы на администраторов подаются в течение 2 дней»); `report.account` — 1.4 (администрация не восстанавливает имущество); `report.help` и `report.offtopic` — 3.1 («репорт не по назначению»), но только если игрок просит телепорт, валюту, уровень или имущество. Для апелляций фраза «Возможное нарушение» в черновике не добавляется: нарушения там нет.
