# C1: определение языка

`app/language.py` возвращает язык, признак неопределённости и смешения. Сервис использует только сообщения player до первого admin. Подсказка server_lang не заменяет язык текста.

Без модели работает консервативная эвристика. Общие казахские/узбекские буквы қ/ғ не определяют язык. Учтены отличительные буквы, несколько узбекских латинских слов и варианты апострофов. Неопределённые латинские тексты остаются lat, слишком короткие и смешанные — und. Эвристика считается уверенной только в ясных случаях: русский текст из 8+ кириллических букв без казахских/украинских/белорусских признаков, узбекская латиница с двумя узбекскими словами, казахский с двумя специфическими буквами или длинным текстом, английский с двумя английскими словами. Остальное (короткие фрагменты, украинский и белорусский, смешение, неопределённая латиница) остаётся language_uncertain и needs_human=true. Ники и коды правил (sk, gz, dm) при определении языка не учитываются.

Опциональный backend — локальный fastText lid.176: он поддерживает kk и uz, тогда как Lingua не покрывает uz. Источники: [fastText language identification](https://fasttext.cc/docs/en/language-identification.html), [языки Lingua](https://github.com/pemistahl/lingua-py). Модели fastText распространяются по CC BY-SA 3.0; перед распространением включить лицензию и атрибуцию. В репозиторий модель не добавлять.

Установка optional extra: `python -m pip install -e '.[language]'`. fastText может требовать C++ toolchain и подходящий Python; этот backend в текущем Python 3.14 не устанавливался и на реальной модели не проверялся. Не менять системное окружение ради него без необходимости.

Укажите `GRAND_LANGUAGE_MODEL_PATH` на собственный доверенный локальный lid.176.bin или lid.176.ftz. Модель загружается один раз на процесс при первом подходящем запросе. Ошибка настройки/загрузки останавливает обработку, без скрытой подмены backend. Автоматической загрузки модели и внешней передачи обращений нет.

Принимаются ru/kk/uz/en/es/pt с вероятностью не ниже 0.8 и отрывом от второго результата не меньше 0.2. Это предварительные пороги, требующие проверки на ручном gold, а не калиброванная вероятность. Неизвестный язык даёт und и человека. Явное смешение кириллицы и латиницы также даёт language_mixed; это приближение, игровые слова и никнеймы могут вызвать ложное срабатывание. Смешение ru/kk в одной письменности пока надёжно не определяется. Показатель confidence ответа относится к категории, не к языку.

Проверены синтетические сценарии и контракт backend. Качество kk/uz, транслитерации и пороги на реальных данных ещё не измерены. Черновики остаются нейтральными шаблонами и требуют оценки носителей.
